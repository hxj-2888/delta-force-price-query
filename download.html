三角洲行动 · 变卖物价格查询

安装到手机或电脑，随时查实时价格

📲 方式一：安装为应用（推荐）PWA · 免下载安装包

1
手机（iPhone / Android）：用浏览器打开后，点浏览器菜单 → 「添加到主屏幕」/「安装应用」，桌面即出现应用图标。
2
电脑（Windows / Mac）：用 Edge / Chrome 打开，地址栏右侧出现安装图标 → 点击安装。
🟢 立即打开在线应用

💻 方式二：便携版 ZIP

⬇️ 下载便携版（Win 解压即用，需安装 Node.js）

解压后双击 start.bat 启动本地服务器，浏览器访问 localhost:3000。首次运行按提示配置上游 API Token。
